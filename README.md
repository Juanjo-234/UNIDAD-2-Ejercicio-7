Resolución del ejercicio N°7 de la unidad 2 de programacion 2.
Este programa simula la gestión de pedidos en un restaurante.
Automatiza el flujo operativo para que la orden tomada por el personal de atención sea enviada y registrada automáticamente en el área de preparación de alimentos.
Las clases utilizadas en este modelo son:

Plato: Representa los productos del menú con sus atributos de nombre, precio y tiempo de preparación.
Pedido: Agrupa una lista de platos junto con el número de mesa correspondiente.
Cocina: Administra la recepción y el almacenamiento de las comandas en una cola de pendientes.
Mozo: Gestiona el rol de atención y se encarga de transmitir el pedido hacia la cocina.
